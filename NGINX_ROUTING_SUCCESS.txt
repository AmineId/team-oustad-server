📱 CONFIGURATION FLUTTER

Utilisez ces URLs dans votre application Flutter :

```dart
// lib/config/api_config.dart
class ApiConfig {
  // URL de base
  static const String BASE_URL = 'https://app.team-oustad.com';
  
  // OTA Update endpoints
  static const String OTA_CHECK_URL = '$BASE_URL/android/check-update';
  static const String OTA_VERSION_URL = '$BASE_URL/android/version.json';
  static const String OTA_DOWNLOAD_URL = '$BASE_URL/android/download';
  
  // Exemple d'utilisation
  static String checkUpdateUrl(int currentVersion) {
    return '$OTA_CHECK_URL?current_version=$currentVersion';
  }
}
```

Exemple d'appel API :

```dart
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<void> checkForUpdate() async {
  final packageInfo = await PackageInfo.fromPlatform();
  final currentVersion = int.parse(packageInfo.buildNumber);
  
  final url = Uri.parse(
    ApiConfig.checkUpdateUrl(currentVersion)
  );
  
  final response = await http.get(url);
  
  if (response.statusCode == 200) {
    final data = json.decode(response.body);
    
    if (data['update_available'] == true) {
      // Afficher dialogue de mise à jour
      final version = data['latest_version'];
      print('Update available: ${version['version_name']}');
      print('Changelog: ${version['changelog']}');
      print('Download: ${version['download_url']}');
    }
  }
}
```

🆘 DÉPANNAGE

Problème : Endpoints non accessibles
Solution : 
   1. systemctl status nginx
   2. nginx -t
   3. tail -f /var/log/nginx/error.log

Problème : Certificat SSL invalide
Solution :
   1. certbot certificates
   2. certbot renew
   3. systemctl reload nginx

Problème : 502 Bad Gateway
Solution :
   1. pm2 status
   2. pm2 restart teamfitness-preprod
   3. pm2 logs teamfitness-preprod

Problème : APK ne télécharge pas
Solution :
   1. Vérifier que l'APK existe : ls -la public/android/
   2. Vérifier les permissions : chmod 644 public/android/app-release.apk
   3. Vérifier les logs Nginx
