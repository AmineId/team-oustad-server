🚀 PROCHAINES ÉTAPES

1️⃣  DÉPLOYER VOTRE APK

   # Depuis votre machine avec Flutter
   cd /chemin/vers/flutter/app
   flutter build apk --release

   # Sur le serveur
   cd /root/team-server/db-server
   ./scripts/deploy-android-apk.sh \
     ~/flutter/app/build/app/outputs/flutter-apk/app-release.apk \
     1 \
     "1.0.0" \
     "Version initiale de Team Fitness"

2️⃣  CONFIGURER FLUTTER

   Dans votre app Flutter, ajoutez :

   ```dart
   // lib/config/api_config.dart
   class ApiConfig {
     static const String OTA_UPDATE_URL = 
       'https://app.team-oustam.com/android/check-update';
   }
   ```

   Code complet : docs/development/flutter_ota_service_example.dart

3️⃣  TESTER

   # Test des endpoints
   ./scripts/test-android-ota.sh

   # Test manuel
   curl https://app.team-oustam.com/android/version.json

⏰ VÉRIFICATION AUTOMATIQUE

L'app Flutter vérifiera automatiquement les mises à jour :
   • Au démarrage de l'application
   • Maximum une fois toutes les 24 heures
   • Peut être désactivé dans les préférences
