📱 CONFIGURATION FLUTTER

┌────────────────────────────────────────────────────────────────────────┐
│ Option 1: Toggle Beta dans l'app (Recommandé)                          │
└────────────────────────────────────────────────────────────────────────┘

```dart
// lib/config/api_config.dart
class ApiConfig {
  static const String BASE_URL = 'https://app.team-oustad.com';
  
  // Déterminer le canal depuis les préférences
  static Future<String> getUpdateChannel() async {
    final prefs = await SharedPreferences.getInstance();
    final isBeta = prefs.getBool('beta_channel_enabled') ?? false;
    return isBeta ? 'beta' : 'production';
  }
  
  static Future<String> getCheckUpdateUrl(int version) async {
    final channel = await getUpdateChannel();
    final path = channel == 'beta' ? '/android/beta' : '/android';
    return '$BASE_URL$path/check-update?current_version=$version';
  }
}
```

```dart
// lib/settings/beta_settings_page.dart
class BetaSettings extends StatefulWidget {
  @override
  Widget build(BuildContext context) {
    return SwitchListTile(
      title: Text('Programme Beta'),
      subtitle: Text('Recevoir les mises à jour beta en avant-première'),
      value: _isBetaEnabled,
      onChanged: (bool value) async {
        final prefs = await SharedPreferences.getInstance();
        await prefs.setBool('beta_channel_enabled', value);
        
        setState(() {
          _isBetaEnabled = value;
        });
        
        // Vérifier immédiatement les mises à jour
        _checkForUpdates();
        
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text(
              value 
                ? 'Canal Beta activé - Vous recevrez les mises à jour en avant-première' 
                : 'Canal Production activé'
            ),
          ),
        );
      },
    );
  }
}
```

┌────────────────────────────────────────────────────────────────────────┐
│ Option 2: Builds séparés avec variables d'environnement                │
└────────────────────────────────────────────────────────────────────────┘

```dart
// lib/config/api_config.dart
class ApiConfig {
  static const String BASE_URL = 'https://app.team-oustad.com';
  
  static const bool IS_BETA = bool.fromEnvironment(
    'IS_BETA',
    defaultValue: false,
  );
  
  static String get updatePath => 
    IS_BETA ? '/android/beta' : '/android';
  
  static String get OTA_CHECK_URL => 
    '$BASE_URL$updatePath/check-update';
}
```

Compilation:
```bash
# Version beta
flutter build apk --release --dart-define=IS_BETA=true

# Version production
flutter build apk --release --dart-define=IS_BETA=false
```

┌────────────────────────────────────────────────────────────────────────┐
│ Option 3: APK distincts (applicationId différent)                      │

android/app/build.gradle:
```gradle
flavorDimensions "environment"
productFlavors {
    production {
        dimension "environment"
        applicationId "com.teamfitness.app"
    }
    beta {
        dimension "environment"
        applicationId "com.teamfitness.app.beta"
        versionNameSuffix "-beta"
    }
}
```

Compilation:
```bash
flutter build apk --release --flavor production
flutter build apk --release --flavor beta
```
