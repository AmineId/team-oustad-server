📡 NOUVEL ENDPOINT D'UPLOAD

POST https://app.team-oustad.com/android/upload

┌────────────────────────────────────────────────────────────────────────┐
│ 📤 Upload APK avec métadonnées JSON                                     │
├────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│ Headers:                                                                │
│   Content-Type: multipart/form-data                                    │
│   Authorization: Bearer <jwt-token>                                    │
│                                                                         │
│ Paramètres (Form Data):                                                │

│   ⭕ min_supported_version- Version minimale supportée                 │

┌────────────────────────────────────────────────────────────────────────┐

└────────────────────────────────────────────────────────────────────────┘

✅ Accès SSH requis
✅ Fichiers locaux sur le serveur
✅ Pas d'authentification API nécessaire
✅ Backup automatique

Usage:
   ./scripts/deploy-android-apk.sh app.apk 2 "1.0.1" "..." production

Cas d'usage:

   • Accès direct aux fichiers
   • Pas besoin de token JWT

✅ Upload depuis n'importe où
✅ Authentification JWT requise
✅ Backup automatique

Usage:
   ./scripts/upload-apk.sh app.apk 2 "1.0.1" "..." production "token"

Cas d'usage:

   • Dashboard web d'administration
   • Upload depuis machine locale

  -F "version_name=1.0.1" \
  -F "changelog=Bug fixes" \
  -F "channel=production"

┌────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  GitHub Actions CI/CD                                                │
└────────────────────────────────────────────────────────────────────────┘

name: Deploy APK
on:
  push:
    tags: ['v*']

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Build APK
        run: flutter build apk --release
      
      - name: Upload to OTA Server
        run: |
          curl -X POST "https://app.team-oustad.com/android/upload" \
            -H "Authorization: Bearer ${{ secrets.OTA_API_TOKEN }}" \
            -F "apk=@build/app/outputs/flutter-apk/app-release.apk" \
            -F "version_code=${{ github.run_number }}" \
            -F "version_name=${{ github.ref_name }}" \
            -F "changelog=Release ${{ github.ref_name }}" \
            -F "channel=production"

🔐 AUTHENTIFICATION

Pour uploader un APK, vous devez fournir un token JWT valide.

┌────────────────────────────────────────────────────────────────────────┐
│ Obtenir un Token JWT                                                    │
└────────────────────────────────────────────────────────────────────────┘

# Via l'API Login
curl -X POST "https://app.team-oustad.com/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@example.com",
    "password": "your-password"
  }'

Réponse:
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": { "id": 1, "role": "admin", ... }
}

┌────────────────────────────────────────────────────────────────────────┐
│ Permissions Requises                                                    │
└────────────────────────────────────────────────────────────────────────┘

  Role     │ Upload Production │ Upload Beta │
─────────────┼───────────────────┼─────────────┤
  owner    │        ✅         │     ✅      │
  admin    │        ✅         │     ✅      │
  member   │        ❌         │     ❌      │

❌ ERREURS POSSIBLES

┌────────────────┬──────────────────────────────────────────────────────┐
│ HTTP 400       │ Paramètres manquants ou invalides                    │
│ HTTP 401       │ Token JWT manquant, expiré ou invalide               │
│ HTTP 403       │ Permissions insuffisantes (role member)              │
│ HTTP 500       │ Erreur serveur interne                               │
└────────────────┴──────────────────────────────────────────────────────┘

Exemples:

400 Bad Request:
{
  "error": "version_code and version_name are required"
}

401 Unauthorized:
{
  "error": "Authentication required"
}

403 Forbidden:
{
  "error": "Insufficient permissions"
}
